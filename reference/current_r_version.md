# Get the current R version

The version is returned as a string in the format `"major.minor.patch"`
(e.g., `"4.4.0"`), using components from `R.version`.

## Usage

``` r
current_r_version()
```

## Value

A character string representing the full R version.

## Examples

``` r
current_r_version()
#> [1] "4.6.0"
```
